# Configuration templates

The TOML files in this directory contain comments only. They document future
configuration groups without selecting values, defining a parser, or creating a
runtime profile.

- `phone.toml` is for phone-sensor collection and mobile-compatible processing.
- `external_imu.toml` is for future high-rate external-IMU support.
- `training.toml` is for future uncertainty and road-context training jobs.
- `evaluation.toml` is for future replay and blackout-evaluation runs.
