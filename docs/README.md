# Documentation placeholders

This directory contains the decisions that must remain visible while the backend
is only a scaffold. It is not a substitute for implementation documentation.

- `architecture.md` describes component ownership and the intentional feedback
  order between fusion, road candidates, context, and map matching.
- `decisions.md` records choices already made and choices intentionally left open.
- `validation_plan.md` lists the future tests and acceptance evidence required
  before the backend can be considered operational.
